# 大肥鱼 · DeepSeek Harness 抖音插件

Windows 桌面插件，提供暖色本机控制台、主人及指定单聊自动回复、按兴趣筛选视频分享和评论，以及 DSH 账号余额查看。**版本：0.8.0-dev.17，开发预览版。**

## 环境

- Windows 10/11 x64，安装 Microsoft Edge。
- 已安装并启动过 DeepSeek Harness，登录自己的账号、配置可正常聊天的模型。
- 当前适配依据：DeepSeek Harness **0.2.1-rc.2** Windows x64 官方桌面运行时。其他版本需要重新核对插件接口，不保证全部兼容。
- 安装可使用 DSH 自带运行时，无需另外安装 Python、浏览器驱动或 npm 依赖。源码测试使用 Node.js 24。

这是浏览器界面适配器，**不是抖音官方机器人 API**。抖音页面结构变化会影响功能；登录、平台验证需本人操作。

## Windows 安装

1. [下载仓库 ZIP](https://github.com/MATH-1-ZERO/dsh-douyin-fish/archive/refs/heads/main.zip) 并解压，或用 `git clone https://github.com/MATH-1-ZERO/dsh-douyin-fish.git` 克隆到长期保留的位置。路径可以包含中文和空格。
2. 从系统托盘完全退出 DeepSeek Harness。
3. 双击 `Check-Windows.cmd` 检查安装位置，再双击 `Install-Windows.cmd`。
4. 启动 DSH，打开 **左下角账号 → 设置 → 大肥鱼控制台**；也可以在聊天中要求调用 `fish_console_open`。

若 DSH 装在自定义目录，在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Windows.ps1 -DshPath "D:\Apps\DeepSeek Harness"
```

脚本自动查找常见位置和卸载注册信息；调用 DSH 自带的正式插件管理 CLI，使用离线本地链接、禁用依赖安装脚本，并备份原 profile 配置。**安装后请保留仓库目录**，不要移走或删除。脚本不会修改 DSH 二进制、结束你的进程、复制登录信息或开启自动发送。详情：[安装、更新与卸载](docs/WINDOWS.md)。

## 首次配置

安装包不包含任何主人账号、Cookie、聊天、余额或成功验收记录。首次按下面顺序配置：

1. 在 DSH 聊天中发送 [首次启动提示词](docs/FIRST-RUN.md)，先导入默认人设并打开控制台。
2. 控制台 → **私信与运行 → 打开 / 重新连接**，在专用 Edge 登录机器人的抖音账号。
3. 提供自己的**主人公开主页完整链接**（`https://www.douyin.com/user/...`）和**抖音号**，让 DSH 调用 `fish_owner_bind` 完成只读身份绑定。不是昵称，也不是手机号码。
4. 回控制台点击 **读取抖音会话**，选择主人或其他单聊；编辑回复方式，保存，再点击 **启动私信自动回复**。

首次启动跳过当前旧消息；之后才回复新的文字。保存设置会暂停任务，启动是独立操作。首次配置需要通过 DSH 导入人设与绑定主人，后续日常操作在控制台完成。

默认读取额度为每天3次、间隔15分钟，适合小规模检查。持续开发测试可按提示词明确开启 `fish_development_mode` 解除本地读取预约限制；模型和发送预算仍受设置约束。**作息默认关闭**，不会强制套用09:00–22:00或15/30分钟作息。

## 控制台功能

| 页面 | 操作 |
| --- | --- |
| 私信与运行 | 打开/重连专用 Edge，读取当前加载的会话，主人/选定联系人 AI 回复，其他已读取会话固定回复，启动/暂停 |
| 刷视频与互动 | 设置兴趣与避开词，观看节奏，分享原生卡片给主人或一个联系人，在感兴趣的视频下评论 |
| 人格档案 | 编辑名字、主人称呼、人设、语气、偏好 |
| 账单与余额 | 查看 DSH 当前账号钱包与官方用量入口；不是插件逐次扣费统计 |
| 运行状态、时间线 | 查看实际任务与记录；访客预览屏蔽私密数据及操作 |

同时开启分享和评论时，每个视频最多执行其中一种或跳过。筛选根据已读取的标题、说明及可用评论，**没有画面或音频理解**。私信与刷视频切换运行，不能同时控制浏览器。

新账号给主人自动分享卡片之前，需完成一次准确卡片发送及主人确认；步骤见 [首次启动](docs/FIRST-RUN.md)。不附送或伪造作者账号的验证记录。

## 已验证与限制

- 原 dev.16 的411项自动化测试、真实主人会话读取、宿主控制台启动到基线再暂停已验证。
- 本发布版新增可移植 Windows 路径、首次主人绑定、安装检查和空状态测试；测试结果见 [发布验收](docs/VALIDATION.md)。
- 指定联系人持续真实收件、原生卡片、自动评论及长时间多视频循环仍需在实际账号分别验收。不能把模拟测试当作真实送达。
- 仅处理当前已加载的单聊；群聊、附件、语音、未读取联系人不自动处理。消息暂用文本指纹去重，相同正文可能被合并。
- 浏览器9222端口仅监听本机；控制台是随机本机端口，链接仅当次宿主有效。未知送达停下复核，不自动重发。

## 开发与发布

双击 `Test-Windows.cmd`，或安装 Node.js 24 后运行：

```powershell
npm test
npm run check
```

运行代码仅依赖 Node 内置模块和宿主提供的服务，不随仓库打包 DSH、Edge 或第三方插件。仓库中仅保留源码、通用人设、文档、脚本和合成测试数据。不要提交 `.dsh`、`state.json`、浏览器资料、访问片段或截图中的私密内容。本项目采用 [MIT 许可证](LICENSE)。
